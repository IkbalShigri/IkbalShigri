## Featured Projects

### 1. Autonomous Vehicle Safety Enhancement System (AVSES)

**Undergraduate thesis | November 2025 – June 2026**

A video-based deep learning project for recognizing vehicle rear-signal events and motorcyclist hand gestures as a seven-class classification task.

- Architecture: MobileNetV3-Small visual backbone, LSTM temporal modeling, and temporal attention.
- Addressed class imbalance using data augmentation, weighted sampling, and class-weighted loss.
- Reported test accuracy: **82.96%**; weighted F1-score: **83.07%**.
- Research manuscript: in preparation.

[View AVSES repository](https://github.com/IkbalShigri/AVSES)

### 2. Motorcyclist Hand-Signal Recognition from Video

**Gesture-only recognition | December 2024 – November 2025**

A separate three-class video classification project recognizing a rider's **left signal**, **right signal**, or **no signal**.

- Architecture: EfficientNet-B0, two-layer Bi-LSTM, and temporal attention.
- Used clip-consistent augmentation without horizontal flipping to preserve left/right labels.
- Reported 44/44 correctly classified held-out test clips (macro-F1: 1.00). The test set is small, so this result is preliminary and should not be interpreted as evidence of generalization.

[View hand-signal recognition repository](https://github.com/IkbalShigri/motorcyclist-hand-signal-recognition)

### 3. Kidney CT Multi-Class Classification

A four-class CT image classification project using **ImageNet-pretrained ResNet50** and **Grad-CAM** to visualize image regions influencing predictions.

- Classes: Cyst, Normal, Stone, and Tumor.
- Used class-weighted cross-entropy to address class imbalance.
- Reported test accuracy: **99.68%**; macro-F1: **99.61%** on the existing test split.
- Academic prototype only; not clinically validated and not intended for medical diagnosis.

[View kidney CT classification repository](https://github.com/IkbalShigri/kidney-ct-classification)
